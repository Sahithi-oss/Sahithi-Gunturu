A secure, full-stack video portal for hospitals with role-based access and direct-to-cloud video delivery.

| Aspect | Details |
|--------|---------|
| **Stack** | React, Spring Boot, AWS S3, PostgreSQL, Keycloak SSO |
| **Security** | Role-Based Access Control (RBAC) via Keycloak OpenID Connect (OIDC) |
| **Storage** | Direct-to-cloud transfers using AWS S3 Presigned URLs (PUT/GET) |

- 🔐 **RBAC with Keycloak OIDC** for secure, role-specific access
- ☁️ **Presigned URL pipeline** keeps the S3 bucket private and offloads server bandwidth
- 📁 **Multi-level category navigation** with dynamic folder-tree sidebars and PostgreSQL metadata sync
- 🎬 **Custom HTML5 video player** with inline playback, timeline scrubbing, speed control and secure time-bound authorization
